# نبذة عن المشروع ومجموعة التقنيات (Project Overview & Tech Stack)

## 1. نبذة عن المشروع (Project Overview)
**أَحَد (Ahaad)** هو موقع عربي خفيف وسريع يجمع أدوات الويب اليومية المفيدة في منصة واحدة بسيطة، هادئة، ومتاحة للجميع. يركز الموقع على الأدوات الحسابية، أدوات التواريخ والتقويم، معالجة النصوص، ضغط وتحويل الصور، وغيرها من المهام اليومية المتكررة.

### المبادئ الجوهرية (Core Principles):
1. **تجربة عربية أصيلة أولاً (Arabic-First UX):** تصميم من الصفر يدعم اتجاه القراءة من اليمين إلى اليسار (RTL) مع خط عربي متزن بصرياً (`IBM Plex Sans Arabic`) وتباعد أسطر مريح يتناسب مع الحركات والتشكيل.
2. **الخصوصية التامة والتشغيل المحلي (Client-Side Privacy):** تعمل الأدوات بالكامل داخل متصفح المستخدم دون رفع أي بيانات أو صور أو نصوص إلى خوادم خارجية، مما يحمي خصوصية المستخدم ويقلل تكاليف التشغيل إلى الصفر.
3. **أداء فائق وحجم خفيف (Zero Bloat & Fast Performance):** توليد موقع ثابت بالكامل (SSG) باستخدام Astro وTailwind CSS، لتحقيق علامة 100/100 في اختبارات Lighthouse.
4. **عناوين دائمة وقابلة للمشاركة (Permanent & Shareable URLs):** كل أداة تمتلك رابطاً ثابتاً ومستقلاً تحت المسار `/tools/[slug]`، مع دعم تضمين المدخلات في معاملات الرابط (URL Query) لمشاركة النتائج فوراً.
5. **العمل دون اتصال (PWA & Offline-First):** يدعم التثبيت على شاشات الهواتف والحواسب وتشغيل الأدوات الأساسية بدون إنترنت عبر Service Worker خفيف.
6. **هوية بصرية هادئة ومنضبطة (Calm Minimalist Aesthetic):** استناد كامل إلى نظام التصميم الموثق في `DESIGN.md` مع خطوط تقسيم واضحة (1px hairlines)، غياب الظلال الضخمة، ودعم الوضعين الفاتح والداكن.

## 2. مجموعة التقنيات (Tech Stack)

### إطار العمل الأساسي (Core Framework):
- **Astro 7 (SSG - Static Site Generation):** توليد صفحات ثابتة ومُحسنة مسبقاً لكل الأدوات والصفحات دون الحاجة لأي خادم يعمل في الخلفية وقت التشغيل.
- **Node.js (>=22.23.4):** بيئة التشغيل لبناء وتطوير المشروع.

### واجهة المستخدم والأنماط (Styling & Design System):
- **Tailwind CSS v4 (`@tailwindcss/vite` & `tailwindcss` 4.3.3):** بناء الأنماط بالاعتماد على محرك Vite الفائق والجديد، مع استغلال خاصية `@theme` لتعريف توكنز التصميم والألوان والخطوط.
- **الخطوط (Typography):** خط **IBM Plex Sans Arabic** مستضاف محلياً بصيغة WOFF2 الحديثة لتجنب طلبات خوادم خارجية وضمان العمل التام أوفلاين وسرعة التحميل الفورية.
- **الأيقونات (Icons):** أيقونات `lucide` (SVG مدمجة وخفيفة الوزن ومطابقة تماماً للهوية البسيطة).

### التفاعلية وجزر الواجهة (Interactive Islands):
- **Preact (`@astrojs/preact`):** مكتبة خفيفة للغاية (~3KB) للتعامل مع الحالة التفاعلية المعقدة في الأدوات (مثل حاسبة العمر، النسبة المئوية، ضغط الصور) عبر نمط جزر Astro (`client:load` / `client:idle`) مع إبقاء باقي الصفحة HTML خالصاً.
- **Vanilla JavaScript:** للوظائف البسيطة مثل شريط التصفية السريع وتبديل الوضع الليلي ومزامنة الرابط.

### محركات المعالجة والحسابات (Processing & Algorithms):
- **معالجة التواريخ والتقويم الهجري:** استخدام واجهات المتصفح القياسية المدمجة `Intl.DateTimeFormat` مع تقويم `islamic-umalqura` (حسابات صفرية الحجم معتمدة رسمياً ومحدثة عبر المتصفح).
- **معالجة وضغط الصور:** استخدام واجهات المتصفح القياسية HTML5 `Canvas API` و`createImageBitmap` للضغط والتحويل الفوري لصيغ WebP وJPEG داخل المتصفح.

### إدارة الحالة والمزامنة (State Management):
- **URL Search Parameters (`URLSearchParams`):** المصدر الأول للأسبقية لمشاركة النتائج.
- **LocalStorage API:** الحفظ والاسترجاع التلقائي للمدخلات عند إعادة فتح الأداة.

### السيو وإمكانية الوصول (SEO & Accessibility):
- **HTML5 دلالي متوافق مع قارئات الشاشة ومعايير WAI-ARIA.**
- **Schema.org Structured Data:** بيانات مهيكلة بصيغة JSON-LD من نوع `WebApplication` لكل أداة.
- **OpenGraph & Twitter Cards:** وسوم مخصصة للمشاركة الجذابة عبر الشبكات الاجتماعية وتطبيقات المحادثة.
- **Sitemap & Canonical URLs:** خريطة موقع مولدة تلقائياً عبر `@astrojs/sitemap` وروابط معيارية موحدة.

### البنية التحتية والاستضافة (Hosting & Infrastructure):
- **استضافة ثابتة 100%:** لا تتطلب أي قواعد بيانات أو خدمات خلفية (يمكن نشرها مجاناً على Cloudflare Pages، GitHub Pages، Vercel، أو Netlify).
