# دليل شاشات واجهة المستخدم (UI Screens Guide)

يحتوي هذا المجلد على توثيق تخطيطي وهندسي لشاشات الموقع لمساعدة مطوري الواجهة ووكيل الذكاء الاصطناعي على بناء وتكويد الشاشات بدقة تامة طبقاً لملف نظام التصميم `DESIGN.md` وملف الأنماط `src/styles/global.css`.

## الشاشات الموثقة:
- [`screens.md`](./screens.md): يشمل المخططات الهيكلية (Wireframes)، وتفاصيل توزيع العناصر، وحالات التفاعل، وقواعد التجاوب والوضع الليلي لكل شاشة من شاشات المنصة.
